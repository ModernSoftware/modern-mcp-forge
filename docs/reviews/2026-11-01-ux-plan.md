## Replay the SQLite quote workflow

1. Create a native Node tool named `get_quote_by_sku`. Keep the source ID, or use a domain name such as `quotes` if more operations will share the pack.
2. Copy the repository, service, domain, and handler modules from the earlier SQLite example into that source folder. Match the imports to the directories you actually created. In the recording the handler is under `./implementations/create-quote.js`.
3. The final frame calls `resolve(...)` and registers `create_quote`. Import `resolve` from `node:path` and register the handler under the exact key specified by the manifest. For the default generated binding use `tools: { get_quote_by_sku: createQuoteHandler(service) }`. Return a worker `close()` method that closes the repository.
4. The sample constructs its database path from `context.config.databasePath`. In Advanced source files, set `workers.main.config.databasePath` to `./data/quotes.sqlite` in `mcpack.json`.
5. For the sample's persistent quote-creation service, add a required string `requestId` alongside required `sku` (string) and `quantity` (integer). The service uses this key to replay a quote. A pure price lookup can instead have its own two-argument service.
6. Install third-party npm packages in the native source directory. Commit `package.json` and `package-lock.json` and use `npm ci` in a clean checkout. The sample's `node:path`, `node:crypto` and `node:sqlite` imports are Node built-ins. Use a worker Node version with `node:sqlite` available.
7. Select **Reload files & restart sources**. If startup fails, open **Show worker diagnostics**, correct the named file or configuration, and reload again. Test with `{"requestId":"review-1","sku":"MCP-BOOK","quantity":2}`. Expect a USD total of 5000 cents. Reload and repeat with the same request ID to verify the persisted quote.
8. Keep Forge running with the project open. In **Workspace → Connect an agent**, copy the URL into the local client's Streamable HTTP transport. Discover tools, then call the same tool. Reconnect clients after a restart.

The file check covers ordinary JS/TS/Python source files, the pack manifest and common dependency declarations and lockfiles inside the source. It skips installed packages, virtual environments, symlink targets and application data. Reload explicitly after changing a dependency in place or editing a module outside the source folder. A running MCP client retains its current session until sources restart.
